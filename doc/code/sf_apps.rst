sf.apps
========

.. currentmodule:: strawberryfields.apps

.. automodule:: strawberryfields.apps

Application references
----------------------

The original standalone tutorials are not included in this source distribution.
These reference sections link to the local API descriptions and examples used
by the corresponding applications.

.. _apps-sample-tutorial:

Generating samples
^^^^^^^^^^^^^^^^^^

:mod:`strawberryfields.apps.sample` provides sampling functions and helpers for
encoding graph problems in Gaussian boson sampling circuits.

.. _apps-clique-tutorial:

Maximum clique search
^^^^^^^^^^^^^^^^^^^^^

See :mod:`strawberryfields.apps.clique` for clique-search and postprocessing
functions, including their inputs and examples.

.. _apps-subgraph-tutorial:

Dense subgraphs
^^^^^^^^^^^^^^^

:mod:`strawberryfields.apps.subgraph` documents the dense-subgraph search
functions and their use with sampled candidate subgraphs.

.. _apps-sim-tutorial:

Graph similarity
^^^^^^^^^^^^^^^^

:mod:`strawberryfields.apps.similarity` describes the graph feature vectors and
similarity calculations implemented by this package.

.. _apps-points-tutorial:

Point processes
^^^^^^^^^^^^^^^

See :mod:`strawberryfields.apps.points` for point-process sampling utilities.

.. _apps-vibronic-tutorial:

Molecular vibronic spectra
^^^^^^^^^^^^^^^^^^^^^^^^^^^^

:mod:`strawberryfields.apps.qchem.vibronic` documents the molecular data,
circuit construction and energy calculations used for vibronic spectra.
