# Security policy

## Maintained code

KharonByte maintains this independent Strawberry Fields fork. The current
maintenance target is the `master` branch; no KharonByte package release has
been published. See [SUPPORT.md](SUPPORT.md) for the tested environments and
maintenance limits.

Security reports may concern the library, its dependencies, packaging or
repository automation. Include the affected commit or version.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/KharonByte/strawberryfields/security/advisories/new).
Do not post exploit details or credentials in a public issue.

Include a short description of the impact, the affected component, environment
versions, and a minimal reproducer using synthetic data. Omit real credentials
and private research data.

We will assess reports privately and coordinate fixes and disclosure where
appropriate. This is best-effort maintenance without a guaranteed response time.

## Other problems

Use the [issue tracker](https://github.com/KharonByte/strawberryfields/issues)
for routine installation, numerical-correctness and documentation problems.
If a problem may have security impact, use the private reporting route.
